# Fase 2a — Mostrador (TPV) Implementation Plan

**Goal:** Sell cards over the counter from the account's inventory, with cash, own card terminal or the shop's own Stripe, and keep a sales history with returns.

**Architecture:** Pure models and money maths in `src/core/sales_models.py`; services in `src/services/sales/` (store, inventory, checkout, Stripe gateway, Stripe settings); NiceGUI pages `src/ui/pos.py` and `src/ui/sales.py`. All file and network work behind `run.io_bound`.

**Tech Stack:** NiceGUI 3.13, Pydantic 2, `requests` for the Stripe REST API (no SDK), `segno` for the QR.

**Spec:** `docs/superpowers/specs/2026-11-12-fase2a-tpv-design.md`

## Global Constraints

- No commits unless Ferran asks. Icons only from IconKit, self-hosted in `static/icons`.
- Tests write to temp dirs; never call Stripe (fake HTTP session).
- Amounts are integer cents everywhere inside `sales`; floats only at the UI edge.
- UI text in Spanish. Contact shown anywhere: info@nordicbyte.co.uk.

## Review Focus

1. Stock changed by another window between cart and charge — reject, nothing deducted.
2. Stripe session paid after the page was closed — reconciled on `/ventas`.
3. Returning a sale whose card/variant no longer exists in the collection — recreated.
4. Another account's sales or Stripe key reachable — never.
5. Stripe key in a log line, toast or HTML — never.

## Tasks

### Task 1 — Models and money (`src/core/sales_models.py`, `tests/test_sales_models.py`)
`to_cents(value) -> int`, `format_money(cents, currency) -> str`, `SaleLine`, `Sale`,
`Discount(kind: 'none'|'percent'|'amount', value)`, `subtotal_cents(lines)`,
`discount_cents(subtotal, discount)`, `total_cents(lines, discount)`, `change_cents(total, received)`.

### Task 2 — Editors (`collection_editor.py`, `game_collections.py`, `tests/test_sales_stock.py`)
`CollectionEditor.take_stock(collection, line) -> None` / `return_stock(collection, line)`;
same on `GameCollectionEditor`. `take_stock` raises `OutOfStock(line, available)`.

### Task 3 — Inventory and store (`src/services/sales/inventory.py`, `store.py`, tests)
`sellable_items(games) -> list[StockItem]`, `search(items, text, limit)`;
`take(lines)` all-or-nothing across collections, `give_back(lines)`.
`SalesStore(root)`: `next_number()`, `save(sale)`, `get(id)`, `month(yyyy_mm)`, `months()`, `pending_stripe()`, `to_csv(sales)`.

### Task 4 — Stripe (`src/core/secret_box.py`, `src/services/sales/stripe_gateway.py`, `stripe_settings.py`, tests)
`protect(text) -> str` / `reveal(blob) -> str`; `StripeGateway(key, session)`: `check()`,
`create_checkout(sale, success_url) -> (id, url)`, `status(id) -> 'paid'|'open'|'expired'`,
`expire(id)`, `refund(id)`; `StripeError(message)`. `save_key`, `load_key`, `key_summary`, `forget_key`.

### Task 5 — Checkout (`src/services/sales/checkout.py`, tests)
`charge(lines, discount, method, received_cents, currency, root) -> Sale` (cash/card);
`start_stripe(...) -> Sale(pending)`, `settle_stripe(sale_id) -> Sale`, `cancel_stripe(sale_id)`,
`refund(sale_id) -> Sale`, `reconcile_pending()`.

### Task 6 — UI (`src/ui/pos.py`, `src/ui/sales.py`, `settings_games.py`, `layout.py`, `main.py`, tests)
Routes `/tpv`, `/ventas`, public `/tpv/pagado`; nav entries only in shop mode; Stripe card in Ajustes;
`receipt_html(sale, shop)`; `qr_svg(url)`.

### Task 7 — Scanner queue per account (deferred minor from 1b)
Requests and recent scans carry the owner account; each page only sees its own.
